## Local checks

```powershell
php api\tests\billing_test.php
Set-Location web
npm install
npm run build
```

The seeded demo passwords are `admin123!` for `admin` and `guard123!` for both guards. Change them immediately after deployment. Generate replacements with:

```powershell
php api\tools\generate_hash.php "your-new-password"
```

## AlwaysData API deployment

1. Import `schema.sql` in the AlwaysData phpMyAdmin database. It intentionally contains no `CREATE DATABASE` or `USE` statement.
2. Create or open the `/parking` web folder in AlwaysData and upload the contents of `api` directly into it using FileZilla.
3. Copy `config.sample.php` to `config.php` and fill in the AlwaysData MySQL host, database name, user, password, a long JWT secret, and the exact frontend origin. Do not upload `config.sample.php` as `config.php` without replacing its placeholder values.
4. Ensure PHP has PDO MySQL enabled and Apache allows `.htaccess` overrides. The included rewrite sends `/parking/...` requests to `index.php`.
5. Set the frontend API URL to `https://pondmate.alwaysdata.net/parking`.

The API sets `Asia/Manila` in PHP and executes `SET time_zone = '+08:00'` for each PDO connection. All entry, exit, and billing timestamps are generated by the API.

## Frontend deployment

1. Deploy `web` to Vercel or an AlwaysData Node.js/static hosting service.
2. Set `NEXT_PUBLIC_API_URL` to the public API URL, for example `https://parking-api.example.com/api`.
3. Add the deployed frontend origin to `frontend_origin` in `api/config/config.php`.
4. Rebuild/redeploy after changing environment variables.

## API summary

- `POST /api/auth/login`
- `POST /api/tickets/entry`
- `GET /api/tickets/{token}`
- `POST /api/tickets/{token}/checkout` with `confirm_payment: false` for a preview or `true` to close the ticket
- `POST /api/tickets/lost`
- `GET /api/dashboard/stats`
- `GET, PUT /api/rates`
- `GET, POST /api/users` (admin settings)
- `GET /api/transactions`

The QR code contains only a 32-byte random ticket token. Plate numbers and database IDs are never encoded in the QR payload.
